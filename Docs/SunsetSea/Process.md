# 高山观景台与云海落日

本阶段新建 SunsetSea 高山观景台场景，采用石质平台、侧面木栏、前沿矮墙、程序化山峰和单个大尺度云体。原有 MistForest 继续保留。人物通过共用的第一人称控制器在平台上行走，出生位置和跌落复位高度由场景单独设置。

初版平台地面与山峰占据较大画面，云海不够突出。调整时将相机移到平台前沿、减少中央山峰数量，并提高云层厚度。随后降低太阳光强，减轻日落前云顶过亮。天空使用渐变色与太阳圆盘，太阳方向与方向光同步。该天空属于艺术化近似，尚未实现完整的大气散射。

按 1、2、3 切换日落前、日落时、日落后，对应太阳仰角 20°、4°、-6°，主光强度为 0.65、0.55、0.08。三个状态共同调整太阳颜色、天空颜色和天空补光。云形、密度与相机在对照中固定，风速设为 0。最终视线、太阳和天空采样预算分别为 48、3、1。

截图使用 Unity 6000.6.0f1、Direct3D 11 与 RTX 4070 Laptop GPU，以 1280 × 720 输出。相机位置为 (0,39.2,-4)，向下俯视 8°，视场角 62°。云区 (500,320)，尺寸 600 × 160 的显示亮度均值依次为 217.68、148.33、88.43，呈现白暖、粉橙和冷蓝紫的过渡。该数值是输出图像的亮度统计。

固定日落时状态，分别关闭云体、关闭不透明深度截断和恢复正常截断。在左侧区域 (0,280)，尺寸 140 × 150 内，有 3,257 个像素在正常图中与无云参考各通道相差不超过 1，而关闭截断后至少一个通道相差超过 5。该对照说明山脊能阻挡其后方的云。山前已有云的区域仍会出现正确的体积叠加。

平台碰撞检查确认落地、横向行走和前沿矮墙阻挡均通过。另在 Play 模式通过 Input System 向正常 Update 输入 A、空格和数字 3，验证行走位移、跳跃上升、1.65 米视点高度以及日落后切换。鼠标操控手感与所有边角的长期漫游尚未全面测试。

打开 Assets/Scenes/SunsetSea.unity 并进入 Play，点击 Game 后使用 WASD 行走、Shift 奔跑、空格跳跃、鼠标观察。R 回到平台，Esc 释放鼠标，F2 切换画质。Cloud Study 菜单中的 Capture Sunset Sea 可复现三时段与遮挡截图。
